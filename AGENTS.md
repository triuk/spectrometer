# Projekt: webová aplikace pro ovládání spektrometru

## Repozitář

Hlavní repozitář projektu:

https://github.com/triuk/spectrometer

Obsah složky `externalSources/` považuj za referenční a neupravuj jej, pokud to nebude výslovně požadováno.

## Cíl projektu

Cílem je vytvořit funkční webovou aplikaci pro práci s kamerovým spektrometrem Little Garden Spectrometer.

Aplikace má být vytvořena pomocí HTML, CSS a JavaScriptu a má fungovat přímo v moderním webovém prohlížeči bez nutnosti instalovat desktopovou aplikaci.

## Referenční zdroje

### 1. Theremino Spectrometer 5.0

Primárním zdrojem pro pochopení algoritmů a očekávaného chování je:

`externalSources/theremino`

Tato složka obsahuje zdrojové kódy Theremino Spectrometer 5.0.

### 2. Little Garden Spectrometer

Zdrojové kódy varianty určené pro Little Garden Spectrometer jsou ve složce:

`externalSources/lgs`

Použij je jako referenci pro změny specifické pro tento přístroj a pro porovnání s Theremino Spectrometer.

### 3. spectro-cam-rs

Doplňkový referenční projekt:

https://github.com/DerFetzer/spectro-cam-rs

Použij jej jako inspiraci pro moderní uživatelské rozhraní, strukturu aplikace a funkce, které původní Theremino nemusí obsahovat nebo je řeší méně přehledně.

Nepřebírej automaticky jeho architekturu ani zdrojový kód. Nejprve ověř, zda je dané řešení vhodné pro webovou aplikaci v HTML, CSS a JavaScriptu.

### 4. Praktické informace o přístroji

Pro pochopení konstrukce, používání, kalibrace a omezení Little Garden Spectrometer využij také:

https://goughlui.com/2025/03/08/quick-review-the-little-garden-spectrometer/

https://budgetlightforum.com/t/little-garden-spectrometer-impressions-opinions-discussion/225545

https://scientistnobee.wordpress.com/2025/09/27/my-thoughts-on-the-low-cost-garden-spectrometer/

Tyto stránky používej jako praktické a experimentální zdroje, nikoli jako závaznou technickou specifikaci.

## Pravidla implementace

Při konfliktu zdrojů nebo nejasném chování problém výslovně popiš. Nevybírej řešení pouze podle toho, co je obvyklé, pokud jej nelze doložit zdrojovým kódem, dokumentací nebo naměřenými daty.
